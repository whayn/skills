# Security policy

Security fixes target the current `main` branch; there is no guaranteed response
time and older snapshots are not maintained separately.

## Report privately

Use [GitHub private vulnerability reporting](https://github.com/{{OWNER}}/{{REPO}}/security/advisories/new).
Do not put exploit details, credentials or private data in public issues or pull
requests. If the private form is unavailable, contact
[@{{OWNER}}](https://github.com/{{OWNER}}) to arrange a private channel first.

Include the affected revision, impact, a minimal synthetic reproduction and any
suggested mitigation.
